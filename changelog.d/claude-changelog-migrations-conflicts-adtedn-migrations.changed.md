- **Migration entries are now per-PR fragments under `migrations.d/` (#564, epic #561).** Like the changelog (#563), `MIGRATIONS.md` no longer has a shared `## [Unreleased]` section: a PR that breaks an API or changes runtime behavior adds one `migrations.d/<branch-slug>.md` file holding a complete templated entry, and the "Release Notes" workflow assembles fragments into a dated section (`towncrier.migrations.toml`). The historical Unreleased content is frozen as `## [2026-07-09]`. The docs-site `/migrations` include and consumers of `MIGRATIONS.md` are unaffected.
