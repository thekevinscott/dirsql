- **Fan-out file→table matching:** a file matching multiple tables' globs now populates **every** matching table — each `Table` is an independent view over the files matching its glob — replacing the previous "first matching table wins" routing. Captures are resolved per-glob, deletions fan out to every matching table, and declaration order no longer affects routing. The persistent cache is now keyed by `(rel_path, table_name)` (sidecar schema version `3` → `4`), so an existing cache is discarded and rebuilt once on the first run after upgrading.
