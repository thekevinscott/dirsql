**Added** `await db.query(sql, params)` and `await db.queryOrdered(sql, params)` bind `params` to the statement's placeholders through SQLite: an array fills `?` placeholders in order, a plain object fills `:name` / `@name` / `$name` placeholders by name. Values never enter the SQL text, so text holding quotes needs no escaping. Works for path-tables and declared tables alike. Values bind as SQLite's native types (`null`, `number`, `bigint`, `boolean`, `string`, `Buffer` / `Uint8Array`); any other value, `undefined` included, rejects with a `TypeError`, and a `bigint` outside the signed 64-bit range with a `RangeError`. A wrong parameter count, a missing or unused name, or the wrong container rejects with an error naming the problem.
