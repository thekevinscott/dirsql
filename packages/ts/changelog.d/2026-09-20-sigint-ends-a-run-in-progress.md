**Fixed** Ctrl-C now ends a `dirsql` run that is still in progress through the npm launcher. The launcher's `process.on("SIGINT")` listener could never fire during a scan: the addon's `runCli` export is synchronous, so it blocks the event loop for the whole of the core's run and the listener is only reached once the work has already finished. The addon now drops SIGINT and SIGTERM to their default disposition for that window, which the kernel acts on unaided, matching the standalone binary. `dirsql server`'s graceful shutdown still exits 0 — the core registers its own handler over the default once it starts.
