**Changed** Building over a tree that exhausts inotify's watch limit fails with an `std::io::Error` (`DirSqlError::Io`, kind `StorageFull`) whose `DirSqlError::os_error()` is errno 28, `ENOSPC` and the message `inotify watch limit reached`, as watchdog raises; any other error starting the watcher also fails the build, except a table directory that does not exist yet. Once built, a new directory the watcher cannot watch, or the OS dropping file events, makes every later query fail until the instance is rebuilt.
