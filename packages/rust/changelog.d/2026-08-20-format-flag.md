**Added**

- **`--format {auto,table,json}` decides how result rows are rendered**, in the REPL and `dirsql query` alike. `auto` (the default) reads the **destination**: a table when stdout is a terminal, the JSON array when it is piped or redirected — so `SELECT * FROM './'` in a large tree lays itself out to be read instead of putting a few thousand JSON objects in front of a person, while `dirsql "…" | jq` keeps receiving byte-identical JSON. It keys on stdout, not stdin, so `dirsql > rows.json` typed at a terminal still writes JSON. `--format table` and `--format json` override in either direction, including into a pipe. There is no `.mode`: dirsql has no dot-commands to extend, and a flag serves the one-shot query too; `dirsql server` does not accept it, since its transport is JSON over HTTP. Tables are aligned columns with a rule under the header, a row count, `NULL` spelled out so it cannot be read as an empty string, control characters escaped (`\n`, `\t`, `\u{…}`) so one row cannot span several lines, and cells truncated past 60 characters so one `content` column cannot set the width of every row. `--format json` returns values unaltered.
