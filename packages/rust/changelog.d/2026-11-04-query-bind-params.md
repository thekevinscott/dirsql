**Added** `DirSQL::query_with`, `query_ordered_with`, `query_each_with` and `AsyncDirSQL::query_with` bind a `Params` to the statement's placeholders through SQLite: `Params::Positional` fills `?` placeholders in order, `Params::Named` fills `:name`, `@name` and `$name` placeholders by name. Values never enter the SQL text. Works for path-tables and declared tables alike. A wrong parameter count, a missing or unused name, or the wrong variant for the placeholders is a `DbError::Params` naming the problem.
