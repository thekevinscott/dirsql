**Fixed** An absolute or `~/` path-table resolves `..` through the filesystem, as the shell does, instead of folding it out of the string first. After a symlinked directory, `'/r/y/link/../f.md'` now reads the file `cat` reads (the link target's parent), and `path` reports the name as written (`/r/y/link/../f.md`), matching the `./` and `../` forms. Windows keeps its own lexical `..` handling.
