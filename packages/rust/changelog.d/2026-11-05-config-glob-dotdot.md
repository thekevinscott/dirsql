**Fixed** A config `[[table]] glob` with an absolute, `~/`, or `../` prefix resolves `..` through the filesystem, as the shell does, instead of folding it out of the string first. After a symlinked directory, `glob = '/r/y/link/../*.md'` now matches the files `ls` lists (in the link target's parent). The `on-file` hook receives the paths, and `{root}`, with the `..` as written. Windows keeps its own lexical `..` handling.
