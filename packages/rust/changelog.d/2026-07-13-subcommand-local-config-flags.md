**Changed** — Config flags for `dirsql query` are now subcommand-local: pass `-c`/`--config`, `--persist`, and `--extension` **after** the subcommand (`dirsql query "<sql>" -c <cfg>`). A config flag placed *before* the subcommand is now a hard error (`the subcommand 'query' cannot be used with '--config <CONFIG>'`) instead of being silently dropped when it straddled the subcommand boundary. Server mode (no subcommand) is unchanged.
