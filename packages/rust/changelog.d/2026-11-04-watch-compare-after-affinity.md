**Fixed** A watch refresh compares rows as the table stores them, after column affinity. A hook that emits a number into a `TEXT` column, a numeric string into an `INTEGER` column, an integer into a `REAL` column, or `-0.0` no longer emits an `update` (or a delete plus insert) on every re-run for rows whose stored values never change, and `insert` and `update` events carry the row as `query` returns it.
