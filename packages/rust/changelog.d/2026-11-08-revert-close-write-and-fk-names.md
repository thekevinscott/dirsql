**Changed** Reverted two changes from the previous release while their design is reviewed. On Linux, watched files are read on create and modify again, not only on close-write or rename-in, and the `MovedIn` file-event variant is gone. A foreign-key violation error again names the first offending table and file through `ForeignKeyViolation::table` and `ForeignKeyViolation::file`; the `offenders` list is gone.
