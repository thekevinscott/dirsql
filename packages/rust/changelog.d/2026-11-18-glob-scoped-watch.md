**Fixed** The live watcher puts a watch only on the directories a table glob can reach and the directories on the way to them, instead of on every directory under the root. Narrowing a table's glob now narrows the watch count, so a config restricted to one table over a large tree no longer exhausts the inotify watch limit at build. A symlinked directory a glob reaches is watched at its target when that lies under the root, including directories created there later.
