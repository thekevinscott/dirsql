**Fixed** `query` (CLI, REPL, `POST /query`, every SDK) runs exactly one statement and rejects any SQL after it. `dirsql "SELECT 1; SELECT 2"` used to print the first statement's rows and exit 0, dropping the second statement — or unparseable text after the `;` — unseen. It now fails with `query() runs one statement at a time; remove the SQL after the first statement` (HTTP `400`). A trailing `;`, whitespace, or a comment after the statement is still accepted.
