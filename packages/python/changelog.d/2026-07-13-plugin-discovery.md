**Added** — The `pip`/`uvx` launcher now auto-discovers installed plugins: a package that ships a `dirsql.toml` fragment behind a `[project.entry-points.dirsql]` entry point is loaded automatically (installed = active), its tables queryable with zero config edits. The fragment is composed after the user's own `-c` configs, and the baked-in `files` table is preserved (via the internal `--include-default`). Opt out with `--no-plugin` or `DIRSQL_NO_PLUGIN=1`. Discovery is launcher-only — the compiled binary and the SDK never auto-discover.
