**Fixed** A query no longer applies the file watcher's queued events: it reads the index as it stands, so a writer that never pauses can no longer hold a query indefinitely. The watcher's events are applied in the background as they arrive, so a write reaches the index shortly after it returns; on Linux a query issued the moment a write returns may now read the previous rows. `watch()` reports the changes applied after it attaches, so a change applied before then is no longer streamed.
