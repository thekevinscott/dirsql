**Added** `await db.query(sql, params)` binds `params` to the statement's placeholders through SQLite: a sequence fills `?` placeholders in order, a mapping fills `:name` placeholders by name. Values never enter the SQL text, so text holding quotes needs no escaping. Works for path-tables and declared tables alike. Values bind as SQLite's native types (`None`, `int`, `bool`, `float`, `str`, `bytes`, `bytearray`); any other type raises `TypeError`. A wrong parameter count, a missing or unused name, or the wrong container raises an error naming the problem.
